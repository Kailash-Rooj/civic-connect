# CivicConnect — Sample Data

## Purpose

This directory is intended for documenting safe, fictional data used to test CivicConnect.

## Sample Complaint

Use the following example when manually creating a test complaint through the application:

- **Category:** Roads & Potholes
- **Description:** A pothole requires repair near a public road.
- **Location:** Select an appropriate test location on the map.
- **Photograph:** Use a sample image that you own or are permitted to use.
- **Status:** Submitted

## Test Accounts

Create separate citizen and administrator test accounts using the application's supported account-creation process. Administrator accounts must be provisioned through the private administrative setup process.

Never store real passwords, session secrets, API keys, database credentials, or personal information in sample data.

## Usage

1. Start the application or open the deployed demo.
2. Create or sign in with a test account.
3. Submit fictional complaints and exercise the documented test cases.
4. Clean up test records where appropriate and permitted.

**Note:** The examples above are instructions for creating test data, not preloaded database records.
